# Hospital Pharmacy Prescription Analysis

Analysis of 26,715 pharmacy prescription records to find which medicines are dispensed the most and which medicine classes cost the most.

**Data:** Kaggle hospital management dataset . Patient details were not used.

**Tools:** Python, Pandas, Matplotlib

**Key findings**
- Guaifenesin/Dextromethorphan was dispensed the most (83,598 units).
- Chemotherapy / Antineoplastic had the highest total cost (about USD 4.59 million).
- High-risk medicines cost about USD 50.52 per unit on average, against USD 7.84 for normal ones.
